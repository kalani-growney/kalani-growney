### What I'm building

**[Notebook](https://notebook.kalanigrowney.com)**
A full-stack replacement for the Runestone Python notebook, built after using it in class and finding it slow with no help when you get stuck. Features an AI helper that reads page context, in-browser Python editors, and a step-through code visualizer. Shaped by user testing with students.
`Next.js` `TypeScript` `Postgres` `Vercel`

**CrisisOS**
A wildfire disaster-response command center for decision support. Combines real public data from NASA, NOAA, and OpenAQ with clearly labeled synthetic modeling, provenance tracking, and an audit trail.
`Next.js` `TypeScript`

**[WorkJourney](https://apps.apple.com/us/app/workjourney/id6760629488)**
An iOS app for logging work and tracking progress, live on the App Store with CarPlay support for hands-free logging. Built with a small team.
`iOS` `CarPlay`
